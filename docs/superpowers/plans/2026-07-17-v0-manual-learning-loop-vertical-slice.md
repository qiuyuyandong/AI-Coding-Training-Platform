## Scope
### Must have
- A transactionally imported `software-development-foundations-v1` package with exactly 12 published nodes, 12 reviewed primary resources, 12 mapped practice tasks, explicit prerequisite edges, and nine read-only career summaries.
- A minimal canonical-problem identity layer linking each practice task to one canonical problem and one public source; existing Phase 0 `problems` rows remain unchanged.
- Accessible `/map` and `/map/[nodeId]` server pages: the keyboard-readable list is primary and a labelled static SVG/CSS route overview is supplementary.
- One stable local learner profile, optional primary direction plus at most two interests, a resumable six-prompt diagnosis, four non-mastery baselines, and a user-recorded starting-point override on `/plan`.
- A pure, versioned deterministic planner powering `/today`: exactly one primary task, at most three on-demand semantic alternatives, 15/30/60/90-minute investment boundaries used only as ranking input, persisted reason codes, deterministic tie-breaking and an explicit safe fallback.
- Three additive migrations named `0006_curriculum_catalog.sql`, `0007_learner_goals_and_plans.sql`, and `0008_ability_projection.sql`; migration and package upgrades must preserve existing Phase 0 data.
- An atomic plan-item completion service that creates one manual attempt, links it to the item and node, records completion feedback, replays ability, creates a replacement daily-plan snapshot and returns visible reasons/uncertainty without partial state.
- Minimal ability storage for `unassessed + L1–L5`; V0 E1 manual evidence ordinarily advances only `unassessed→L1→L2`, cannot create L4/L5, discounts short repeats, and does not downgrade on one ordinary failure.
- Correction and void routes automatically replay mapped-node ability from all active attempt revisions in the same transaction; identical replay must not duplicate transitions.
- One optional 30-second reflection field plus one optional AI-generated reflection question after completion. It is disabled by default, invoked only when the learner checks a per-request opt-in, uses a server-only local environment key and allowlisted structured metadata, is not persisted, and falls back to a deterministic question on every failure.
- Agent-executed unit, migration, content, API, accessibility and Playwright verification under disposable databases; explicit content and privacy audit artifacts.
