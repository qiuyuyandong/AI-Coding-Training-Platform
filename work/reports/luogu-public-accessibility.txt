=== DISTINCTION: CONTENT ACCESSIBILITY vs DOM ACCESSIBILITY ===

"Content accessible" means: the page returned HTTP 200 to a public request and some
human-readable content was extractable (e.g., problem title via Jina markdown).

"DOM accessible" means: the raw HTML DOM was captured and analyzed, including
specific CSS selectors (.status, .record-status, .submission-status),
element hierarchy, and text node structure.

This task found public CONTENT but no public DOM. Every problem page returned
rendered Markdown/text through Jina but not raw HTML DOM. No record page was
accessible without authentication.
